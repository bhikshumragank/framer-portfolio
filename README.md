# Mragank Bhikshu · Framer Portfolio

Code components, case studies and visual assets behind my portfolio site, built in [Framer](https://www.framer.com).

**Live site:** https://mragankbhikshu-portfolio.framer.website

I'm a product and brand designer from IIT Kharagpur. The site covers case studies on AI assistants, hiring tools and ticketing UX, along with brand identities, posters and motion work.

## What's inside

Each `.tsx` file in the root is a standalone Framer code component (React + TypeScript), pasted into the Framer project as a code file.

## Using a component

1. In Framer, open **Assets → Code** and create a new code file.
2. Paste in the contents of a `.tsx` file from this repo.
3. Drag the component onto a page and adjust its properties in the right-hand panel.
