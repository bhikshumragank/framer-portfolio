## Three ways I design

### UI/UX design
I start with the person on the other side of the screen: a conductor on a moving bus, an HR team buried in paper forms, an investor deciding whether to tap. I map their flows, cut the steps that don't earn their place, and test the result against real conditions.

- User research, journey mapping and task analysis
- Information architecture and user flows
- Wireframes, interactive prototypes and usability reviews
- Accessible, responsive interfaces built for glare, one thumb and small screens

### Product design
I take a problem from a fuzzy brief to a shipped product, working with engineers and stakeholders along the way. I care about what happens after launch, not just what the mockup looks like.

- Product thinking: scoping, edge cases and state models
- Design systems and reusable components
- Admin tools, dashboards and role-based experiences
- Designing AI features that behave honestly: answer from real data, refuse to guess

### Visual design
I build visual systems that hold up across 70 assets as well as they do across one. This covers brand identity, packaging, campaign creatives, mascots, posters and film.

- Brand identity, logo and packaging design
- Campaign, social and event creatives
- Mascot and illustration systems
- Motion graphics and brand films

## The portfolio as a design project

The site is a case study in its own right. Instead of a grid of thumbnails, it's a **space-themed world** you move through. A ship flies in on the loading screen, the home page is a spaceship bridge with rooms to explore, and the work gallery is an exhibition hall with five wings. Sparky, the mascot I designed, guides you around.

Every scene is a custom Framer code component that I designed and built, so the interactions are exactly what I intended, not the limits of a template.

### Using a component in Framer
1. Open **Assets → Code** and create a new code file.
2. Paste in a `.tsx` file from this repo.
3. Drag the component onto a page and adjust it from the properties panel. Text, colours and content are all editable there.
